Module flux3 

Source
Expand description

3D face kernels (Cartesian), ported one-to-one from crate::flux: MUSCL reconstruction, HLLC, Rusanov, the shock-sensor blend and the low-Mach correction, all projected on a unit normal n: [f64; 3]. The limiters, limited_slope, shock_weight and the sensor / low-Mach constants are shared with 2D.

Functions§

face_flux3
Complete face kernel: MUSCL reconstruction + HLLC, blended towards Rusanov inside shocks (see crate::flux::face_flux).
face_flux_lm3
face_flux3 with the optional low-Mach correction; low_mach = false is exactly face_flux3.
face_rot
Cylindrical frame about the x axis at a face centroid c: [sin, cos] of its azimuth, [c_y / r, c_z / r] with r = hypot(c_y, c_z); [0, 1] on the axis.
hllc3
HLLC flux for the 3D Euler equations projected on the unit normal n (see crate::flux::hllc). The contact wave carries both tangential velocity components passively. Returns F.n per unit face area.
low_mach_states3
Low-Mach correction of the reconstructed face states: scales only the jump of the face-normal velocity by z = clamp(max(M_L, M_R), LOW_MACH_FLOOR, 1) (see crate::flux::low_mach_states).
reconstruct3
MUSCL reconstruction of the primitive variables at the face between cells m1 (left) and p0 (right); m2 and p1 are the outer neighbours. The lateral velocity is limited in the face’s cylindrical frame about the x axis (rot = face_rot(centroid): radial v s + w co, tangential v co - w s), so axisymmetric flow stays exactly axisymmetric; the reconstructed states are transformed back. Falls back to first order for a side whose reconstructed density or pressure is not positive.
rusanov3
Rusanov (local Lax-Friedrichs) flux projected on n: 0.5 (F_L + F_R) - 0.5 smax (U_R - U_L) with smax = max(|un_L| + c_L, |un_R| + c_R).
