Functions§

face_flux
Complete face kernel: MUSCL reconstruction + HLLC, blended towards Rusanov inside shocks. m2, m1 | p0, p1 are the four primitive cell states around the face (m1/p0 adjacent to it).
face_flux_lm
face_flux with the optional low-Mach correction low_mach_states applied to the reconstructed states before the Riemann solvers; low_mach = false is exactly face_flux.
hllc
HLLC flux (Toro, Riemann Solvers and Numerical Methods for Fluid Dynamics, ch. 10) for the 2D Euler equations, projected on the unit normal (nx, nr). Wave speeds: Einfeldt/Roe-averaged estimates SL = min(unL-cL, u~-c~), SR = max(unR+cR, u~+c~). Returns the flux per unit face length F.n (no geometric weighting).
limited_slope
Limited cell slope phi(a, b) with a = q_i - q_{i-1}, b = q_{i+1} - q_i. Face values are q_i +- phi/2.
low_mach_states
Low-Mach correction of the reconstructed face states (Thornber et al., “An improved reconstruction method for compressible flows with low Mach number features”, J. Comput. Phys. 227 (2008) 4873): the jump of the face-normal velocity between the left and right state is scaled by z = min(max(M_L, M_R), 1) (M = |V|/c of the reconstructed states, floored at LOW_MACH_FLOOR):
reconstruct
MUSCL reconstruction of the primitive variables at the face between cells m1 (left) and p0 (right); m2 and p1 are the outer neighbours. Falls back to first order for a face whose reconstructed density or pressure is not positive.
rusanov
Rusanov (local Lax-Friedrichs) flux, projected on (nx, nr): 0.5 (F_L + F_R) - 0.5 smax (U_R - U_L) with smax = max(|un_L| + c_L, |un_R| + c_R). Dissipates every wave family (incl. contact/shear) at the maximum rate.
shock_weight
Weight theta in [0, 1] of the Rusanov flux in face_flux: smoothstep of the relative pressure jump between the two cells adjacent to the face (Quirk-type shock sensor). 0 in smooth flow (pure HLLC), 1 inside a captured shock (pure Rusanov); C1-continuous so the steady state stays a smooth fixed point.
