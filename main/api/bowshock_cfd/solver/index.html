bowshock_cfd

Module solver 

Source
Expand description

Finite-volume solver: MUSCL (primitive variables) + HLLC/Rusanov shock blend, SSP-RK3 with local time stepping as the reference (Scheme::Explicit), optionally accelerated by implicit residual smoothing (Scheme::Smoothed) or FAS multigrid (Scheme::Multigrid, see multigrid.rs); optional low-Mach flux correction and a blocked (solid) body region for base/wake grids.

Per-iteration data flow (every stage is a plain data-parallel kernel):

  1. cons -> prim per cell, then ghost-cell fill (2 layers per side, no corner ghosts needed);
  2. flux per i-face / j-face (face_flux: MUSCL reconstruct + HLLC blended to Rusanov in shocks);
  3. per-cell residual dU/dt = -(1/V) sum_f w_f F_f + (0,0,pA/V,0) (+ multigrid forcing) and local dt;
  4. optional implicit residual smoothing (Jacobi-iterated, all-cells-parallel).
  5. optional viscous terms (Solver::set_viscous, see viscous.rs): per-cell gradients and viscosity, viscous face fluxes Fv that enter the cell residual as F - Fv, no-slip wall ghost states.

Structs§

Block
Solid body region of the structured grid. Cells i < i_end && j < j_end are inside the body, and (with a sting) cells i >= i_end && j < j_sting are inside the sting; they are never updated.
Config
Irs
Variable-coefficient implicit residual smoothing (Jameson / Martinelli): (1 - eps_i d_ii)(1 - eps_j d_jj) R_bar = R, each factor a conservative scalar tridiagonal system along the grid lines, solved exactly (Thomas algorithm per line, lines in parallel; a GPU port can use one thread per line or parallel cyclic reduction). The time step is the usual dt = CFL A / (L_i + L_j) (L_d = spectral-radius sum of the two faces of direction d); each direction whose directional CFL number c_d = dt L_d / A exceeds cfl_star is smoothed with eps_d = ((c_d / cfl_star)^2 - 1) / 4.
MgParams
FAS multigrid parameters (see multigrid.rs).
Nozzle
Nozzle exit on the base face: rows 0..j_end of i = i_end are a fixed inflow state instead of a wall (needs a block with j_sting == 0); rows j_end..block.j_end stay wall (the annulus).
Solver
Viscous
Viscous-flow parameters (non-dimensionalisation of viscous.rs: rho_inf = c_inf = 1, lengths in nose diameters).
