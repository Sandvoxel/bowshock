Low-Mach correction of the reconstructed states (flux::low_mach_states), off by default.

§grad: Vec<[f64; 6]>

Viscous run: cell gradients (u_x, u_r, v_x, v_r, T_x, T_r), laminar viscosity and eddy viscosity per cell (ni*nj) as of the last residual evaluation; empty without viscous terms.

§mu: Vec<f64>§mu_t: Vec<f64>§rough_wall: Vec<[f64; 3]>

Rough-wall run (Viscous::rough): [k_w, omega_w, mu_t,w] (Aupoix wall state, turbulence::aupoix_wall) of the cells that have a no-slip face, from the primitives of the last residual evaluation (read by the turbulence update and by viscous::face_mu); empty otherwise.

§turb: Vec<[f64; 2]>

SST run: specific turbulence kinetic energy and specific dissipation rate [k, omega] per cell, the distance of every cell centroid to the nearest no-slip wall face, and the density residual norm of k of the last update; empty / zero otherwise.

Select the convergence scheme. For Scheme::Multigrid the coarse levels are built from the current grid and block (call Solver::set_block first); returns the number of levels (1 for the other schemes).

pub fn set_block(&mut self, block: Option<Block>)

Declare the solid body block (cells inside it are frozen at the free stream and excluded from the residual norm).

Source

pub fn set_nozzle(&mut self, n: Option<Nozzle>)

Declare the nozzle exit on the base face (None: all base rows are wall). The block must be declared before (Solver::set_block) and the viscous terms after (Solver::set_viscous); an already allocated SST wall distance is recomputed. Needs Scheme::Explicit, Scheme::Smoothed or Scheme::Implicit.

Source

pub fn nozzle(&self) -> Option<Nozzle>

Nozzle exit on the base face, None if the whole base is wall.

Source

pub fn block(&self) -> Option<Block>

Solid body block (base/wake grids), None for ordinary grids.

Source

pub fn set_viscous(&mut self, v: Option<Viscous>)

Switch the viscous terms on (Some) or off (None, the Euler equations). Allocates the per-cell gradient, viscosity and face-flux arrays; with Turbulence::Sst also the turbulence state (free stream) and the wall distance, so the body block must be declared before. Viscous runs support Scheme::Explicit and Scheme::Implicit only.

Source

pub fn viscous(&self) -> Option<Viscous>

Viscous-flow parameters, None for the Euler equations.

Source

pub fn noslip_jface(&self, i: usize, j: usize) -> bool

Is the j-face (i, j) (between cells j - 1 and j of column i) a no-slip wall? Always false for the Euler equations.

Source

pub fn scheme(&self) -> Scheme

Convergence acceleration in use (set with Solver::set_scheme).

Source

pub fn prim(&self, i: usize, j: usize) -> Prim

Primitive state of interior cell (i, j) as of the last residual evaluation.

Source

pub fn eval_residual(&mut self, compute_dt: bool)

Evaluate res = dU/dt for the current self.u; optionally the local time step self.dt.

Source

pub fn density_residual(&self) -> f64

L2 norm of d rho / dt, normalised by sqrt(N) (N = number of fluid cells). Includes the multigrid forcing.

Source

pub fn step(&mut self) -> f64

One iteration with the configured Scheme; returns the density residual at the start of the iteration (of the finest grid, before any smoothing of the residual).

Source

pub fn turb_residual(&self) -> f64

L2 norm of rho dk/dt of the last turbulence update over the fluid cells, normalised by sqrt(N) (0.0 without SST).

Source

pub fn pressure(&self, i: usize, j: usize) -> f64

Pressure at the cell centre of (i, j) from the conserved state.
