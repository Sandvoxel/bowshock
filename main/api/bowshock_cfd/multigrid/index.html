FAS (full approximation storage) multigrid for the steady Euler iteration, built from the same per-cell / per-face kernels as the explicit solver, so that every operation is all-cells-parallel (no sequential sweeps).

Hierarchy: the grid is coarsened by removing every second node line (Grid::coarsen, 2x2 cells -> 1 cell, requires even ni, nj); coarse levels use first-order reconstruction (cheap, robust), the same BCs, the free stream and, with a blocked body region, the halved block.

One cycle on level l (rates R = dU/dt as in Solver::eval_residual, the coarse problem is dU/dt = R_c(U) + P):

  1. pre SSP-RK3 smoothing steps (local time stepping, optional implicit residual smoothing);
  2. defect d = R_l(U_l) (+ P_l); restriction of the state U_c = sum V U / sum V and of the defect P_c = sum V d / sum V - R_c(U_c) (volume weighted, fluid cells only);
  3. gamma cycles on level l+1 (the coarsest level takes coarsest smoothing steps);
  4. prolongation of the correction U_l += I(U_c - U_c^0) (index-space bilinear, solid coarse cells excluded, damped by halving until density and pressure are positive);
  5. post smoothing steps.

The converged state of a cycle is the converged state of the fine-grid (second-order) discretisation: the coarse correction vanishes with the fine-grid defect.
