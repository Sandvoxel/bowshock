Module grid3 

Source
Expand description

3D structured finite-volume grid: node coordinates, face area vectors, cell volumes.

Cell (i, j, k) is the hexahedron between node lines i..=i+1, j..=j+1, k..=k+1. The index layouts are fixed by the field docs; faces are oriented towards increasing index regardless of the handedness of the node mapping.
