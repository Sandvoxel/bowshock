Module gas3 

Source
Expand description

3D ideal-gas helpers, the Cartesian counterpart of crate::gas. State layouts:

  • conservative Cons3 = [rho, rho*u, rho*v, rho*w, E], E = p/(g-1) + rho (u^2+v^2+w^2)/2
  • primitive Prim3 = [rho, u, v, w, p]

Velocities are Cartesian: u axial (x), v lateral (y), w vertical (z). Incidence alpha > 0 means the air moves towards +z relative to the body, so the windward side is -z and a positive normal force points to +z.
