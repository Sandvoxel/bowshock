Module solver3 

Source
Expand description

3D Euler finite-volume solver on a Grid3 (CPU, f64, rayon): MUSCL + HLLC/Rusanov face fluxes of crate::flux3, SSP-RK3 with local time stepping (Scheme3::Explicit) or the three-factor line-implicit scheme of crate::implicit3.

The data flow is the 2D one of crate::solver with one more direction and no source term:

  1. cons -> prim per cell into the padded array w (2 ghost layers on every side of all three axes, [pidx3]);
  2. ghost fill (no corner ghosts: all stencils are 1D);
  3. flux per i / j / k face (face_flux_lm3; the lateral velocity is limited in the face’s cylindrical frame, face_rot);
  4. cell residual R = -(1/V) sum_f S_f F_f.

Boundaries (see Solver3::new for the grid conventions): i = 0, i = ni, j = nj characteristic far field; j = 0, i < axis_cells the symmetry axis (ghost = the cell across the axis, found through the pitch-plane symmetry theta -> pi - theta and a sign flip of v); j = 0, i >= axis_cells slip wall; k = 0, k = nk symmetry planes. Cells inside a crate::grid3::SolidBox (fins) are never updated and act as slip walls on their fluid neighbours.
