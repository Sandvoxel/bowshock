Crate bowshock_cfd

bowshock-cfd: axisymmetric compressible Euler / RANS (Menter SST k-omega) finite-volume solver.

  • The CPU solver (always built, f64, rayon): gas, flux (limiters, MUSCL, HLLC), grid, bc, solver (SSP-RK3 and the line-implicit scheme of implicit, FAS multigrid), viscous and turbulence. Every kernel is a plain function of its inputs with no hidden state, so it ports one-to-one to array operations.
  • The GPU solver (cargo feature gpu, on by default): bowshock_cfd::gpu, the same solver written in plain Luma array ops (f32 or double-float), validated against the CPU solver.

Modules§

bc
Characteristic (Riemann-invariant) far-field and static-pressure outflow ghost states.
bc3
3D characteristic far-field and static-pressure outflow ghost states, ported from crate::bc with the outward unit normal n: [f64; 3]. The Riemann-invariant logic acts on the normal velocity; the tangential velocity vector is taken from the upwind side (free stream on inflow, interior on outflow). The 2D Regime is reused.
flux
Face kernels: slope limiters, MUSCL reconstruction and the HLLC Riemann flux.
flux3
3D face kernels (Cartesian), ported one-to-one from crate::flux: MUSCL reconstruction, HLLC, Rusanov, the shock-sensor blend and the low-Mach correction, all projected on a unit normal n: [f64; 3]. The limiters, limited_slope, shock_weight and the sensor / low-Mach constants are shared with 2D.

gpu
The GPU solver (feature gpu): the axisymmetric Euler solver of the CPU modules (MUSCL + HLLC / Rusanov shock blend + optional low-Mach correction, characteristic and pressure-outflow far fields, SSP-RK3 with local time stepping or the line-implicit scheme, optional solid body block) written in plain Luma array ops: no custom kernels. Luma’s lazy arrays fuse the expressions; iterate_until_all traces one step and replays its kernels, recording the density residual on the GPU.
grid
Structured body-fitted grid in the (x, r) meridian plane and its finite-volume metrics.
grid3
3D structured finite-volume grid: node coordinates, face area vectors, cell volumes.
implicit
Line-implicit pseudo-time stepping (Beam-Warming-type approximate factorization, “ADI”) for the steady Euler iteration.
implicit3
Line-implicit pseudo-time stepping for Solver3: the three-factor approximate factorization (“ADI”) of crate::implicit with 5x5 blocks.
multigrid
FAS (full approximation storage) multigrid for the steady Euler iteration, built from the same per-cell / per-face kernels as the explicit solver, so that every operation is all-cells-parallel (no sequential sweeps).
solver
Finite-volume solver: MUSCL (primitive variables) + HLLC/Rusanov shock blend, SSP-RK3 with local time stepping as the reference (Scheme::Explicit), optionally accelerated by implicit residual smoothing (Scheme::Smoothed) or FAS multigrid (Scheme::Multigrid, see multigrid.rs); optional low-Mach flux correction and a blocked (solid) body region for base/wake grids.
solver3
3D Euler finite-volume solver on a Grid3 (CPU, f64, rayon): MUSCL + HLLC/Rusanov face fluxes of crate::flux3, SSP-RK3 with local time stepping (Scheme3::Explicit) or the three-factor line-implicit scheme of crate::implicit3.
turbulence
Menter SST k-omega turbulence model (2003 version) for the viscous solver (Turbulence::Sst).
viscous
Viscous terms of the axisymmetric compressible Navier-Stokes equations (laminar; the eddy-viscosity arrays are carried for the turbulence model but stay zero until it is attached).
