Module gpu 

Source
Expand description

The GPU solver (feature gpu): the axisymmetric Euler solver of the CPU modules (MUSCL + HLLC / Rusanov shock blend + optional low-Mach correction, characteristic and pressure-outflow far fields, SSP-RK3 with local time stepping or the line-implicit scheme, optional solid body block) written in plain Luma array ops: no custom kernels. Luma’s lazy arrays fuse the expressions; iterate_until_all traces one step and replays its kernels, recording the density residual on the GPU.

The solver is in body.rs (explicit scheme) and implicit.rs (line-implicit scheme), each function the mirror of the CPU routine of the same name in the CPU modules of this crate, included once per precision:

  • f32s: Array<f32> everywhere (Precision::F32).
  • df32s: the state, the residual and the time step in double-float Array<Df32> (Precision::Extended); the state is a Df32 record through the loops.

The line-implicit scheme’s left-hand side is f32 in both. The viscous terms of the compressible Navier-Stokes equations (viscous.rs) and the Menter SST k-omega model (turbulence.rs) follow, for both schemes and for grids with a solid block; their left-hand sides (the 2 lam I of the implicit operator, the line solves of the two turbulence scalars) are f32 like the rest. GpuSolver is the precision-independent handle the other crates use. See the README.
