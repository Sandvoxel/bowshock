Expand description

GPU solver of one 3D grid: f32s::LazySolver3 or df32s::LazySolver3 behind one type. Mirrors crate::solver3::Solver3 (SSP-RK3 with local time stepping or the three-factor line-implicit scheme, characteristic far field, axis, slip wall, symmetry planes, fin solid boxes, low-Mach correction). The left-hand side of the implicit scheme is f32 in both precisions.
