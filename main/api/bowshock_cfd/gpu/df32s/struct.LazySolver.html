Expand description

The solver: state, geometry and the loops that advance it, with an optional solid block (base / wake grids). Mirrors crate::solver::Solver with Scheme::Explicit (eval_residual and rk3_step) or Scheme::Implicit (implicit.rs).

pub fn set_viscous(&mut self, v: Option<Viscous>, grid: &Grid) -> Result<()>

Switches the viscous terms on (Some, with the SST model if v.turbulence says so) or off (None, the Euler equations). grid is the grid of the solver: the geometry of the compact face gradients, the cell metrics and the wall distance are computed from it in f64 and uploaded in the precision S. Declare the solid block first; the turbulence state restarts at the free stream (the mean flow is not touched).

pub fn viscous(&self) -> Option<Viscous>

pub fn set_turb(&mut self, turb: &[[f64; 2]], mu_t: &[f64]) -> Result<()>

pub fn turb_state_f64(&self) -> Result<(Vec<[f64; 2]>, Vec<f64>)>

([k, omega], mu_t) of every cell on the host (SST runs; Solver::turb, Solver::mu_t).

pub fn turb_residual(&self) -> Result<f64>

The density residual norm of k of the last turbulence update (Solver::turb_residual; 0 before the first).
