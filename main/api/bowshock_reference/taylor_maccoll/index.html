Taylor-Maccoll solution for supersonic flow over a sharp circular cone at zero incidence.

In spherical coordinates (R, theta) with velocities Vr, Vt made non-dimensional by V_max = sqrt(2 h0) the conical flow obeys (Anderson, Modern Compressible Flow, eq. 10.15)

  Vr'  = Vt
  Vt'  = ( Vt^2 Vr - k (2 Vr + Vt cot(theta)) ) / ( k - Vt^2 ),   k = (g-1)/2 (1 - Vr^2 - Vt^2)

Starting just behind an oblique shock of angle beta (velocity components from the oblique shock relations) the ODE is integrated with RK4 towards smaller theta until Vt = 0, the cone surface. beta is found by bisection such that that angle equals the cone half-angle.
