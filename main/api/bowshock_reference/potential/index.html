Module potential 

Source
Expand description

Incompressible potential flow past a closed body of revolution at zero incidence: an independent reference for the low-Mach Euler results (no CFD code involved).

Method (method of fundamental solutions / axial source distribution): the flow is U e_x plus the field of n_s point sources of unknown strength q_k placed on the axis inside the body,

  V(P) = U e_x + sum_k q_k (P - P_k) / (4 pi |P - P_k|^3),

and the strengths solve the no-penetration condition V.n = 0 at n_c > n_s collocation points on the surface (regularised least squares through the normal equations; the net source sum q_k = 0 is added as a soft constraint). The surface speed gives Cp = 1 - |V|^2 / U^2. Axisymmetric potential flows are represented by axial singularity distributions, so the solution converges to the exact one as the point sets are refined; it is verified against the exact sphere solution (Cp = 1 - 9/4 sin^2 theta) in the unit tests.

Compressibility (linearised, thin body): Goethert’s rule for bodies of revolution, Cp_M[R](x) = Cp_inc[beta R](x) / beta^2, beta = sqrt(1 - M^2) (the Prandtl-Glauert transformation of the axisymmetric small-perturbation equation beta^2 phi_xx + phi_rr + phi_r / r = 0), i.e. the incompressible solution for the body with radius scaled by beta.
