1//! Army-Navy Basic Finner (ANF) reference projectile: geometry and measured static stability derivatives, used to gate the
2//! 3D Euler stability solver and to judge the Barrowman-style (`Extended`) estimate.
3//!
4//! # Source
5//!
6//! Dupuis, A., "Aeroballistic range and wind tunnel tests of the basic finner reference projectile from subsonic to high
7//! supersonic velocities", DRDC Valcartier TM 2002-136 (wind tunnel and free flight), with the supersonic free-flight part
8//! in Dupuis & Hathaway, DTIC ADA636861. Neither report was reachable when this module was written (DTIC was under
9//! maintenance), so the numbers below are **digitised from Yayla (2021), METU thesis, Figure 3.10 (C_Nα vs Mach, p. 35 of
10//! the thesis, PDF p. 57) and Figure 4.4 (C_mα vs Mach, p. 40, PDF p. 62)**, which replot Dupuis's wind-tunnel (WT) and
11//! free-flight (FF) points (<https://open.metu.edu.tr/bitstream/handle/11511/93161/index.pdf>). Replace them with the
12//! tabulated values from Dupuis when a copy is available.
13//!
14//! # Digitisation
15//!
16//! The thesis pages were rendered at 200 dpi, the axis frames located to the pixel, and the marker centres found by
17//! template correlation (green squares = WT, purple circles = FF). Marker overlaps were resolved by hand. Both figures
18//! are in 1/deg about the CG; they are converted to per radian here. Digitised, ±3 % on each of C_Nα and C_mα. The centre
19//! of pressure is derived, so its error is larger: x_cp − x_cg = −C_mα/C_Nα·d is a ratio of two ±3 % numbers, about
20//! ±0.1 cal at 3 cal of lever arm (more in the transonic scatter band, where individual shots differ by 0.05 in C_Nα).
21//!
22//! Where several wind-tunnel markers sit within ΔM ≈ 0.04 of each other (Fig. 3.10 and 4.4 overlap them), they are
23//! averaged into one row; the free-flight shots are kept individually. One free-flight C_mα (M 1.376) was hidden behind a
24//! WT marker in Fig. 4.4 and is read by eye (±0.02).
25//!
26//! # Geometry (Yayla Fig. 3.1, from Dupuis; one caliber = 0.03 m)
27//!
28//! Verified against the figure: length 10 cal; cone half-angle 10° with nose length 2.84 cal (= 0.5/tan 10°) and nose-tip
29//! radius 0.004 cal; cylindrical afterbody 1 cal in diameter; four rectangular fins, chord 1 cal, **exposed** span 1 cal
30//! (3 cal tip to tip), root trailing edge flush with the base; fin thickness 0.08 cal; CG 5.5 cal from the nose; fins
31//! canted 2° (roll only, ignored by the pitch-plane methods). Yayla's text says "20 degree nose cone", which is the
32//! included angle (the figure dimensions 10.0° and 2.84).
33//!
34//! Fin edges are not dimensioned in Fig. 3.1. Abiza et al. (XFlow LBM study of the ANF, p. 3,
35//! <https://www.3ds.com/assets/invest/2024-02/prediction_of_finned_projectile_aerodynamics_using_a_lattice-boltzmann_method_cfd_solution.pdf>)
36//! give a sharp leading edge and a blunt 0.08 cal trailing edge; Shelton, Martin & Silva (NASA, Kestrel/FUN3D, p. 2 and
37//! Table 1, <https://ntrs.nasa.gov/api/citations/20180006293/downloads/20180006293.pdf>) a leading-edge fillet r/d = 0.005
38//! and a 0.1 d trailing edge. The nose geometry above agrees with both.
39//!
40//! # Measurement spread
41//!
42//! Two wind tunnels (DREV, ISL) measuring a similar finned projectile differ by about 11 % in C_Nα and 0.4 cal in x_cp at
43//! M 3 (Dupuis & Berner, ISBS 2001, <http://www.xrayct.com/documents/data/IBS19/EB11_495.pdf>, Fig. 5); treat the
44//! high-supersonic points with that spread in mind, on top of the digitisation error.
45//!
46//! The reference area is the body cross-section π d²/4 and the reference length d. Pitching moment is about the CG, so
47//! `x_cp = x_cg − C_mα / C_Nα` (calibers from the nose tip; C_mα < 0 is stable).
48
49use std::f64::consts::PI;
50
51/// One measured point.
52#[derive(Clone, Copy, Debug, PartialEq)]
53pub struct AnfPoint {
54    pub mach: f64,
55    /// Normal-force slope per radian, reference area π d²/4.
56    pub cn_alpha: f64,
57    /// Centre of pressure from the nose tip (calibers), from `x_cg − C_mα/C_Nα` with the CG at [`CG_CAL`].
58    pub x_cp_cal: f64,
59}
60
61/// Total length (calibers).
62pub const LENGTH_CAL: f64 = 10.0;
63/// Nose cone half-angle (degrees), verified (Fig. 3.1).
64pub const NOSE_HALF_ANGLE_DEG: f64 = 10.0;
65/// Nose length (calibers), verified (Fig. 3.1: 2.84).
66pub const NOSE_LENGTH_CAL: f64 = 2.84;
67/// Fin chord (calibers), verified (Fig. 3.1).
68pub const FIN_CHORD_CAL: f64 = 1.0;
69/// Exposed fin span (calibers), verified (Fig. 3.1).
70pub const FIN_SPAN_CAL: f64 = 1.0;
71/// Fin thickness (calibers), verified (Fig. 3.1: 0.08).
72pub const FIN_THICKNESS_CAL: f64 = 0.08;
73/// Number of fins.
74pub const FIN_COUNT: u32 = 4;
75/// Centre of gravity from the nose tip (calibers), verified (Fig. 3.1: 5.50).
76pub const CG_CAL: f64 = 5.5;
77
78const DEG: f64 = 180.0 / PI;
79
80/// Builds a point from the figures' per-degree values.
81const fn pt(mach: f64, cn_per_deg: f64, cm_per_deg: f64) -> AnfPoint {
82    AnfPoint { mach, cn_alpha: cn_per_deg * DEG, x_cp_cal: CG_CAL - cm_per_deg / cn_per_deg }
83}

128#[cfg(test)]
129mod tests {
130    use super::*;
131
132    #[test]
133    fn data_is_sane() {
134        for set in [WIND_TUNNEL, FREE_FLIGHT] {
135            assert!(set.windows(2).all(|w| w[0].mach < w[1].mach));
136            for p in set {
137                // CNα 8..25 per rad; CP behind the CG and ahead of the base.
138                assert!(p.cn_alpha > 8.0 && p.cn_alpha < 25.0, "{p:?}");
139                assert!(p.x_cp_cal > CG_CAL && p.x_cp_cal < LENGTH_CAL, "{p:?}");
140            }
141        }
142        assert!((NOSE_LENGTH_CAL - 0.5 / NOSE_HALF_ANGLE_DEG.to_radians().tan()).abs() < 0.01);
143    }
