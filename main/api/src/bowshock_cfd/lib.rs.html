1//! `bowshock-cfd`: axisymmetric compressible Euler / RANS (Menter SST k-omega) finite-volume solver.
2//!
3//! * The CPU solver (always built, f64, `rayon`): [`gas`], [`flux`] (limiters, MUSCL, HLLC), [`grid`], [`bc`], [`solver`] (SSP-RK3 and
4//!   the line-implicit scheme of [`implicit`], FAS [`multigrid`]), [`viscous`] and [`turbulence`]. Every kernel is a plain function of
5//!   its inputs with no hidden state, so it ports one-to-one to array operations.
6//! * The GPU solver (cargo feature `gpu`, on by default): `bowshock_cfd::gpu`, the same solver written in plain
7//!   [Luma](https://github.com/flipnoteman/Luma) array ops (f32 or double-float), validated against the CPU solver.
