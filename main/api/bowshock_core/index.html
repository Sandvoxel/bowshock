Crate bowshock_core 

Source
Expand description

bowshock-core: zero-lift drag of axisymmetric rockets versus Mach number (0.1 to 3) from CFD: the axisymmetric Euler or Reynolds-averaged Navier-Stokes equations (k-omega SST) on the GPU (Luma) or the CPU, plus empirical fin drag and a motor-on base flow with the exhaust jet.

Describe the body with BodySpec, optionally add FinSpec fins and a MotorSpec motor, give the flight conditions (FlightConditions) and run an Analysis over Mach numbers to get a Polar. The guide is at https://sandvoxel.github.io/bowshock/.

use bowshock_core::{AftSpec, Analysis, Atmosphere, BodySpec, FinProfile, FinSpec, FlightConditions, MotorSpec, NoseShape, NoseSpec};

let body = BodySpec {
    nose: NoseSpec { shape: NoseShape::TangentOgive, length: 0.30, diameter: 0.10 },
    aft: vec![AftSpec::Tube { length: 0.60 }, AftSpec::Transition { length: 0.10, aft_diameter: 0.08 }],
};
let fins = FinSpec { count: 4, root_chord: 0.12, tip_chord: 0.06, span: 0.08, sweep: 0.06, thickness: 0.003, roughness: 0.0, root_te_to_base: 0.0, profile: FinProfile::Rounded };
let motor = MotorSpec { exit_diameter: 0.05, exit_mach: 2.5, exit_pressure_pa: 101_325.0, total_temperature_k: 1500.0 };
let flight = FlightConditions { atmosphere: Atmosphere::Isa { altitude_m: 0.0 } };

let polar = Analysis::new(&body)?.fins(fins).viscous(flight).motor(motor).run(&[0.5, 0.9, 1.5])?;
for p in &polar.points {
    println!("M {:.2}: CD {:.4} (base {:.4}), {:?}", p.mach, p.drag.total, p.drag.base, p.quality);
}

Functions§

gpu_name
The name of the GPU the solver runs on under Backend::Auto, such as Apple M1 Max or NVIDIA GeForce RTX 3090; None when there is none (or only a software device, which the solver does not use) or the crate is built without the gpu feature. The first call asks the graphics driver (tens of milliseconds); the answer is kept. Luma opens the same adapter (high-performance preference), so this names the device the iterations execute on.
