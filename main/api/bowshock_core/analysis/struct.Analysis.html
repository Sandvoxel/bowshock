pub fn on_progress( self, f: impl Fn(&Progress) -> ControlFlow<()> + Send + Sync + 'static, ) -> Self

Calls f with the state of every run about once per SAMPLE_INTERVAL iterations, from the thread that runs the analysis (see crate::progress). Returning ControlFlow::Break ends the analysis at once with Error::Cancelled. Reporting does not change the iteration or the result of a run that is not cancelled. The monitor of a viscous drag run and of a 3D run is reported as a coefficient on the reference area.

Calls f with each point of Analysis::run_lift as soon as its run ends, from the thread that runs the analysis, with the backend that ran it and, under Backend::Auto when the CPU ran because the GPU did not, the reason (as in LiftPolar::fallback).

Source

pub fn on_point( self, f: impl Fn(&PolarPoint, BackendUsed, Option<&str>) + Send + Sync + 'static, ) -> Self

Calls f with each point of Analysis::run as soon as it is decided (after any extended-precision re-run), from the thread that runs the analysis, with the backend that ran it and, under Backend::Auto when the CPU ran because the GPU did not, the reason (as in Polar::fallback). The comparison sweep of Analysis::estimate_uncertainty is not reported.

Source

pub fn drag_tolerance(self, rel: f64) -> Self

Stops each point once its total drag varies by less than rel (relative to its mean) over the last 500 iterations, instead of the default rule (1e-4 absolute over 2000 iterations, judged from iteration 4000). Needs Analysis::viscous; rel must lie in (0, 0.1]. Measured on the example rocket of the app (coarse grid), 0.002 ends within 0.4 % of a 12 000-iteration solution with about 2.8 times fewer iterations.

Source

pub fn warm_start(self, on: bool) -> Self

Start each Mach number from the converged field of the previous one (default off: measured on the solver, warm-started points needed 2-5 times more iterations than cold starts at every Mach spacing from 0.05 to 0.3, and the GPU implicit scheme diverges on a warm start to Mach 0.8). A warm-started point that ends Failed or Stalled is re-run cold, and the point after a Failed point always starts cold.

Source

pub fn estimate_uncertainty(self, on: bool) -> Self

Also run the sweep one grid level away (level - 1, or level + 1 on the coarsest level) and report the difference of the total drag in PolarPoint::cd_uncertainty. Costs a second sweep.

pub fn roughness(self, ks_m: f64) -> Self

Equivalent sand-grain roughness of the body surface in metres (default 0 = smooth). Needs Analysis::viscous and a dimensional BodySpec; must be finite, >= 0 and below 1 % of the nose diameter.

Source

pub fn fins(self, f: FinSpec) -> Self

Add a set of fins to the drag. Needs Analysis::viscous flight conditions, which give the Reynolds number.

pub fn motor(self, m: MotorSpec) -> Self

Add a rocket motor exhausting through the centre of the base: a motor-on analysis, where the base flow contains the jet (an air jet at the nozzle exit, see MotorSpec). Needs Analysis::viscous and the base wake. The jet’s thrust is not drag: Drag::base covers only the annulus of the base around the nozzle exit.

Source

pub fn run(&self, machs: &[f64]) -> Result<Polar, Error>

Zero-lift drag at each Mach number of machs (each in [0.1, 3.0]). Each point goes to Analysis::on_point as soon as it is decided, so without an uncertainty estimate the reports and the result agree; with one, the reported points have no PolarPoint::cd_uncertainty (the comparison sweep runs after the primary one).

pub fn run_lift( &self, machs: &[f64], alphas_deg: &[f64], ) -> Result<LiftPolar, Error>

Normal force and centre of pressure from a 3D Euler solve, for every Mach number of machs (each in [0.3, 3.0]) at every incidence of alphas_deg (each in (0, 15] degrees).

Needs an analysis built with Analysis::new. The 3D solver integrates the Euler equations on a sting-mounted body with thick fins: viscous settings (Analysis::viscous), roughness, the motor and the wake are ignored, and so are the fin roughness and the 2D fin-drag model. Fins come from Analysis::fins; the grid level from Analysis::resolution. Both slices are sorted ascending; the points are ordered by Mach number, then incidence. Each Mach number starts cold; later incidences start from the field of the previous one, and a warm point that ends Failed or Stalled is re-run cold. A point whose run diverged is re-run once with the implicit CFL limit halved. Coefficients refer to the reference area, x_cp is in metres from the tip. Backends as for Analysis::run.
