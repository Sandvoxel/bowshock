Progress of a running solve: a callback that sees where each run is and can stop it.

The solvers iterate for seconds to minutes per Mach number. Analysis::on_progress registers a callback that is called from the thread that runs the analysis, once per SAMPLE_INTERVAL solver iterations (the interval at which the stop rules sample their monitor), with a Progress snapshot. Reporting reads numbers the solver already has: it does not change the iteration, the stop rules or the result. The callback decides whether to go on: returning ControlFlow::Break ends the run at once and the analysis returns Error::Cancelled.

The callback runs on the solver’s thread between iterations: keep it short (hand the snapshot to a channel, throttle there).
