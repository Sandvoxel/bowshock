# bowshock-reference

Independent reference solutions and wind-tunnel data that the [bowshock](https://github.com/Sandvoxel/bowshock) solver is
validated against:

- `taylor_maccoll`: supersonic cone flow (Taylor-Maccoll equation);
- `shock_expansion`: tangent-cone and shock-expansion theory for ogives;
- `potential`: axisymmetric potential flow (subsonic surface pressure);
- `base_drag`: the empirical free-flight base-drag correlation (Niskanen 2009 thesis, eq. 3.94);
- `arcas`: geometry and axial-force data of the half-scale Arcas sounding rocket (NASA TN D-4013 / D-4014);
- `tp2005`: base pressure with cold air jets (NASA TP-2005).

Each module documents its sources, figure readings and uncertainties.
